# Tampermonkey Scripts

A collection of useful browser userscripts.

## Scripts

### [Twitch Horizontal Flip](https://github.com/Phleesty/tampermonkey-scripts/blob/main/Twitch-Horizontal-Flip.user.js)

Flips the Twitch video horizontally.

- **Shortcut:** `Alt + PageUp`
- [Install](https://raw.githubusercontent.com/Phleesty/tampermonkey-scripts/main/Twitch-Horizontal-Flip.user.js)

### [Twitch & Kick Anti-Background Quality Downgrader](https://github.com/Phleesty/tampermonkey-scripts/blob/main/Twitch-Kick-Anti-Background-Quality-Downgrader.user.js)

Prevents Twitch and Kick from lowering video quality or pausing playback when the tab is in the background.

- [Install](https://raw.githubusercontent.com/Phleesty/tampermonkey-scripts/main/twitch-kick-anti-background-quality-downgrader.user.js)

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Open the installation link for the desired script.
3. Confirm the installation in Tampermonkey.

## Updates

Scripts with update metadata can be updated through Tampermonkey.

To publish an update, increase the script's `@version` and commit the changes to the `main` branch.
